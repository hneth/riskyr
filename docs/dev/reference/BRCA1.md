# Cumulative risk of breast cancer in women with the BRCA1 mutation.

`BRCA1` provides the cumulative risk of breast cancer in a population of
women with the BRCA1 mutation as a function of their age (in years).

## Usage

``` r
BRCA1
```

## Format

A data frame (11 x 2).

`x`: age (in years).

`y`: cumulative risk of developing breast cancer in this (BRCA1)
population.

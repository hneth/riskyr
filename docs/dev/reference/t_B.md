# Cumulative risk curve B (main/transfer task B).

`t_B` provides the cumulative risk of some genetic risk factor for
developing disease B in some target population as a function of age.

## Usage

``` r
t_B
```

## Format

A data frame (17 x 2).

`age`: age (in years).

`crisk_B`: cumulative risk of developing some disease B in the target
population.

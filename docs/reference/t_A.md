# Cumulative risk curve A (main/transfer task A).

`t_A` provides the cumulative risk of some genetic risk factor for
developing disease A in some target population as a function of age.

## Usage

``` r
t_A
```

## Format

A data frame (17 x 2).

`age`: age (in years).

`crisk_A`: cumulative risk of developing some disease A in the target
population.

# Print a frequency box object

`print.box` is a utility method that prints a box object.

## Usage

``` r
# S3 method for class 'box'
print(x, ...)
```

## Arguments

- x:

  A box object

- ...:

  Additional parameters to be passed to
  [`cat`](https://rdrr.io/r/base/cat.html).
